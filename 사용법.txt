TCG도감 (포켓몬 TCG 도감)

실행: index.html 파일을 더블클릭하면 크롬/엣지/웨일 등 브라우저에서 바로 열립니다.
      설치할 것은 없고, 인터넷 연결만 있으면 됩니다.
공유: index.html 파일 하나만 보내 주면 누구나 똑같이 쓸 수 있습니다.

- 카드 목록·이미지: TCGdex 공개 API (국제판/영문 카드, 포켓몬 TCG 포켓 제외)
- 시세: Cardmarket·TCGPlayer 최근 시세 신호의 중앙값, 신호 간 편차로 ± 오차율 계산
- 등급 시세(PSA·BRG·BGS·CGC·TAG): 실거래 데이터가 아닌 추정치. 일반 시세 × 연대별 등급 배율로 계산하며,
  일반 시세가 없는 카드는 --- 로 표시됩니다.
- 즐겨찾기: 각자의 브라우저에 저장됩니다 (기기·브라우저마다 따로)
- src/ 폴더: 수정용 원본. 수정 후 python src/build.py 로 다시 빌드 (index.html 이 갱신됨)
- 대화 열기.bat: 더블클릭하면 이 도감을 만든 Claude Code 대화가 이 폴더에서 이어서 열립니다
