TCG도감 (포켓몬 TCG 도감)

실행: index.html 파일을 더블클릭하면 크롬/엣지/웨일 등 브라우저에서 바로 열립니다.
      설치할 것은 없고, 인터넷 연결만 있으면 됩니다.
공유: index.html 파일 하나만 보내 주면 누구나 똑같이 쓸 수 있습니다.

- 카드 목록·이미지: TCGdex 공개 API (북미판·일본판, 포켓몬 TCG 포켓 제외). 홈의 '북미판 / 일본판' 버튼으로 전환
- 일본판: TCGdex에 카드 목록이 있는 116개 세트. MEGA 시리즈 카드 이미지는 포켓몬 카드 공식 사이트 이미지(data/jp-img.json)를 씁니다.
  썬&문~스칼렛&바이올렛 세트의 포켓몬 카드는 한국 공식 사이트(pokemoncard.co.kr) 한글판 이미지로 채웁니다.
  일본판 세트·카드 이름은 한글로 표시합니다. 트레이너스 이름은 한국 공식 카드 목록과 그림을 대조해 얻은 298종을 씁니다.
  오래된 일본판 세트는 데이터 소스에 이미지가 없어 '이미지 없음'으로 보일 수 있습니다.
- 로고: TCGdex에 없는 로고는 Bulbapedia에서 받아 img/logos 폴더에 넣었습니다 (src/sets_extra.json).
- 시세: Cardmarket·TCGPlayer 최근 시세 신호의 중앙값, 신호 간 편차로 ± 오차율 계산
- 등급 시세(PSA·BRG·BGS·CGC·TAG): 실거래 데이터가 아닌 추정치. 일반 시세 × 연대별 등급 배율로 계산하며,
  일반 시세가 없는 카드는 --- 로 표시됩니다.
- 판본별 시세(영문판·일본판·한국판): 카드 상세에서 탭으로 전환. 일본판·한국판은 같은 일러스트레이터·포켓몬·HP로 찾은
  카드의 Cardmarket 시세를 쓰고, 데이터가 없으면 다른 판본 시세로 추정해 '추정'으로 표시합니다.
- 30주년: 30th Celebration과 클래식 복각 30장을 한 세트로 합쳐 보여 줍니다. 복각 카드 이미지는 img/30th-c 폴더에 있습니다.
- 메인 3D 카드 줄: MA 이상 레어도의 포켓몬·서포트(트레이너) 카드 중에서 열 때마다 무작위로 14장을 고릅니다.
- 즐겨찾기: 각자의 브라우저에 저장됩니다 (기기·브라우저마다 따로)
- src/ 폴더: 수정용 원본. 수정 후 python src/build.py 로 다시 빌드 (index.html 이 갱신됨)
- 대화 열기.bat: 더블클릭하면 이 도감을 만든 Claude Code 대화가 이 폴더에서 이어서 열립니다
